# লাইসেন্স কী জেনারেটর (Unique POS)

এই ফোল্ডারের টুল দিয়ে Unique POS ডেস্কটপ অ্যাপের জন্য লাইসেন্স কী বানানো হয়।
`keys/private.pem` দিয়ে প্রতিটি কী সাইন করা হয়, আর অ্যাপ শুধু পাবলিক কী দিয়ে
যাচাই করে — তাই **ইন্টারনেট ছাড়াই** লাইসেন্স কাজ করে, এবং অ্যাপের ভিতরের কোড
দেখেও কেউ নিজে কী বানাতে পারে না।

> ⚠ `keys/private.pem` হলো মাস্টার চাবি। এই ফাইল কারো সাথে শেয়ার করবেন না,
> Git-এ কমিট করবেন না (`.gitignore`-এ বাদ দেওয়া আছে)। হারিয়ে গেলে পুরোনো
> ইন্সটল করা অ্যাপের জন্য আর কী বানানো যাবে না — ভালো করে ব্যাকআপ রাখুন
> (পাসওয়ার্ড ম্যানেজার বা USB)।

---

## ১. একবারের সেটআপ

```bash
npm run license:init
```

এটি `keys/private.pem` আর `keys/public.pem` বানায় এবং স্ক্রিনে একটি পাবলিক কী
প্রিন্ট করে। সেই পাবলিক কী-টি `electron/license.js` ফাইলের `PUBLIC_KEY_PEM`
এর জায়গায় বসাতে হয় (ইতিমধ্যে বসানো আছে — নতুন keypair বানালে তবেই বদলাতে হবে)।

এরপর স্বাভাবিকভাবে বিল্ড করলেই হবে:

```bash
npm run dist
```

---

## ২. নতুন লাইসেন্স কী বানানো

```bash
npm run license:new
```

চালু হলে প্রশ্ন করবে — শপের নাম, কত মাস, Machine ID (না দিলে যেকোনো PC-তে চলবে),
গ্রেস দিন। শেষে কী-টি স্ক্রিনে দেখাবে, আর `issued.csv`-এ রেকর্ড রেখে দেবে।

একবারে সব দিয়ে চালাতে চাইলে:

```bash
npm run license:new -- --shop "রহিম স্টোর" --months 3
npm run license:new -- --shop "Karim Store" --months 3 --machine CCC5-6C75-9C41
npm run license:new -- --shop "Test" --months 6 --grace 7
```

| ফ্ল্যাগ | কাজ |
|:---|:---|
| `--shop "নাম"` | গ্রাহকের নাম (লাইসেন্সে লেখা থাকে) |
| `--months 3` | কত মাস চলবে (ডিফল্ট ৩) |
| `--expires 2027-03-01` | নির্দিষ্ট তারিখে শেষ হবে (`--months`-এর বদলে) |
| `--machine CCC5-6C75-9C41` | শুধু একটি PC-তে চলবে (না দিলে সব PC-তে) |
| `--grace 7` | মেয়াদ শেষের পর অতিরিক্ত কত দিন চলবে |
| `--serial 0007` | নিজের সিরিয়াল নম্বর |

## ৩. গ্রাহকের কাছে কী পাঠানোর নিয়ম

1. গ্রাহক অ্যাপ খুললে অ্যাক্টিভেশন স্ক্রিনে তার **Machine ID** দেখতে পাবে
   (যেমন `CCC5-6C75-9C41`) এবং "কপি" বাটন আছে।
2. শুধু একটি PC-তে বাঁধতে চাইলে গ্রাহকের কাছ থেকে সেই Machine ID নিন, তারপর:

   ```bash
   npm run license:new -- --shop "রহিম স্টোর" --months 3 --machine CCC5-6C75-9C41
   ```

   সব PC-তে চলতে দিতে চাইলে `--machine` বাদ দিন।
3. প্রিন্ট হওয়া লম্বা কী-টি (`POS1.…`) গ্রাহককে পাঠিয়ে দিন — WhatsApp/ইমেইল কপি-পেস্ট।
4. গ্রাহক অ্যাক্টিভেশন স্ক্রিনে পেস্ট করে **অ্যাক্টিভেট করুন** চাপবে।

এরপর কী-টি `%APPDATA%\Unique POS\license.key` ফাইলে জমা থাকে, তাই প্রতিবার অ্যাপ
খুললে আর দিতে হয় না।

## ৪. মেয়াদ শেষ হলে কী হয়

- মেয়াদ শেষের **১৫ দিন আগে থেকে** অ্যাপ খোলার সময় একবার করে মনে করিয়ে দেবে
  (দিনে একবারের বেশি নয়)।
- মেয়াদ শেষ হয়ে গেলে অ্যাপ **খুলবেই না** — শুধু অ্যাক্টিভেশন স্ক্রিন আসবে।
  নতুন কী দিলেই আগের ডেটা সব অক্ষত রেখে আবার চালু হবে। ডেটা কোথাও যায় না।
- অ্যাপ খোলা রাখলে প্রতি ঘণ্টায় লাইসেন্স চেক হয়; মেয়াদ শেষ হলে অ্যাক্টিভেশন
  স্ক্রিন এসে পড়ে — নতুন কী দিলে কাজ চলতে থাকে, বন্ধ করলে অ্যাপ বন্ধ হয়ে যায়।

---

## ৫. কোন শপকে কী দেওয়া হয়েছে

`issued.csv` ফাইলে প্রতিটি কী-এর রেকর্ড থাকে — সিরিয়াল, তারিখ, মেয়াদ, শপের নাম,
Machine ID আর পুরো কী। মেয়াদ শেষ হওয়ার আগে এই ফাইল দেখে গ্রাহকদের Renewal
এর জন্য যোগাযোগ করা যায়।

---

## ৬. সীমাবদ্ধতা (জেনে রাখুন)

- `app.asar` আসলে একটি zip, তাই অত্যন্ত আগ্রহী কেউ `electron/license.js`-এর
  পাবলিক কী বদলে নিজের কী বানিয়ে ফেলতে পারে। এটি ঠেকাতে কোড সাইনিং বা
  obfuscation লাগে — এটি ঠেকানোর একটু কঠিন বাধা, অটুট তালা নয়।
- Machine ID Windows-এর `MachineGuid` থেকে বানানো (হ্যাশ করে), তাই Windows
  রিইনস্টল করলে ID বদলাতে পারে — তখন নতুন কী দিতে হবে।
- ডেস্কটপ অ্যাপেই লাইসেন্স লাগে। ওয়েব ভার্সনে (Vercel) লাগে না।
